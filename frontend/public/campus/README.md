# Campus photos: drop-in folder

Put `.jpg` files here using **exactly** these names. Each one replaces its placeholder on the Home page automatically, with no code change. Refresh the browser after adding photos.

## Licensing (important)

- Use only photos you took yourself, photos your team has written permission to use, or photos with a license that allows commercial use.
- Photos of identifiable students need their consent (a model release) when used to sell products.
- Don't use Yale's official logos or shield in photos unless Campus Customs has a licensing agreement.
- Record each photo's source and license in `CREDITS.md` in this folder.

## Sizes

| Group | Shape | Minimum size | Notes |
|---|---|---|---|
| `hero-*` | Landscape 16:9 | 2400 × 1400 | Full-screen slideshow. Keep the subject centered; text sits on the left. |
| `scene-*` | Mixed | 1600 px on the long side | Campus beauty gallery |
| `reel-*` | Portrait 4:5 | 1000 × 1250 | Moving student-life reel |

Compress to roughly 300–500 KB each (e.g. with squoosh.app) so the page stays fast.
